# Your Environment Shapes Your Flow

Ever notice how some days you sit down and code for hours without distraction, while other days every 10 minutes you're context-switching, searching for tools, or fighting with your setup?

Your development environment isn't just a background detail—it's the stage where flow state either happens or dies.

## The Traditional Setup Problem

Most developers have setups optimized for... well, traditional development:
- Terminal for running commands
- Editor for writing code
- Browser for documentation, Stack Overflow, GitHub
- Multiple windows, constant switching
- Tools that assume you're doing everything manually

This works, but it's designed for the **interrupt-driven workflow**: write some code, run a command, check an error, Google something, switch back, repeat.

## The Vibe Coding Setup

Vibe coding needs a different environment—one optimized for **conversation and flow**:

- Your AI assistant has full access to your codebase
- Code changes happen through natural language
- Testing, linting, and git operations happen without leaving the conversation
- Context is preserved across your entire session
- You stay in one place, focused, in flow

Claude Code is purpose-built for this experience.
